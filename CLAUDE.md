## Claude Code

`AGENTS.md` above is the canonical project guidance for every agent; keep this file to Claude-specific additions. `.claude/settings.json` backs two of its rules (it holds attribution and file permission rules only; `tests/unit/test_agent_instructions.py` refuses hooks, shell allow entries and any other key): commit and PR attribution are disabled, and Claude's file-reading tools are denied the local operator kit's private keys (`secrets/local/keys/`), recovery material, state backups and recipient credential artifacts (`recipient.json`, `*.conf`, `*config.txt`, `links.txt`), which leaves its catalog, runners, input mappings, inventories, encrypted documents, receipts and logs readable for end-to-end deployment; keep other plaintext secret material out of those readable paths. They are also denied `.env`, `*.tfstate`, decrypted secrets files (`*.secrets.yaml`, `*.secrets.yml`, `*.sops.yaml.dec`, `*.sops.json.dec`), and blue-green's temporary secrets directory. The deny list matches file names, so it misses a custom `VPN_SECRETS_FILE` path with another name, and it does not cover every shell or subprocess read, so the plaintext-secrets hard rule still applies to all commands.
