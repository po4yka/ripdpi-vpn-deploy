# Support

This is a small operator-run project. There is no helpdesk and no
service-level commitment.

- **Questions and problems with the repository:** open a GitHub issue with
  [the issue form](https://github.com/po4yka/ripdpi-vpn-deploy/issues/new/choose).
  Read [the documentation index](docs/README.md) first; most answers are in
  [the quickstart](docs/tutorials/quickstart.md), [the deploy guide](docs/how-to/deploy.md)
  or [the incident runbook](docs/how-to/incident.md).
- **Security problems** (active probing of a live node, a burned address, a
  leaked key): follow [the security policy](.github/SECURITY.md) and report
  privately. Never open a public issue for those.
- **Contributions:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Never put credentials, host addresses, hostnames, client identifiers,
Terraform state, decrypted secrets or inventory into an issue, a comment or
a screenshot. Do not post them at all: a redacted sample that keeps its
shape still identifies a deployment.
