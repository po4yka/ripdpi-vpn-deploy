# Documentation

> **Status:** Current · **Type:** reference · **Tier:** — · **Reviewed:** 2026-10-21

Every page in this tree is listed here with its purpose and tier. The tree
follows the four Diátaxis types plus decisions, research and archive;
[STYLE.md](STYLE.md) defines the folders, the status line and the naming rules.
Tiers come from [the tiering decision](decisions/0002-role-and-doc-tiering.md):
CORE pages keep the baseline running, TACTICAL pages cover opt-in situations,
RESEARCH pages describe unconfirmed techniques, EXCEPTION pages cover the
hosting-jurisdiction exception, and a dash marks pages outside that question.

Start here:

1. [Quickstart](tutorials/quickstart.md) builds a first node.
2. [Architecture](reference/architecture.md) maps profiles to roles and ports.
3. [Deploy](how-to/deploy.md), [rollback](how-to/rollback.md), [rotate](how-to/rotate.md),
   [restore](how-to/restore.md) and [incident](how-to/incident.md) are the operator lifelines.
4. [Secrets](reference/secrets.md) and [age recovery](how-to/age-recovery.md) govern the only state that cannot be recreated.

Machine-readable index: [llms.txt](llms.txt), generated by `vpnd ai-docs`.
