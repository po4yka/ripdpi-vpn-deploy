## Goal

Make node lifecycle and Ansible role work discoverable through concise project skills, and eliminate manual JSON assembly of the supported disposable promotion intent through a local validated Make command.

## Acceptance criteria

- Five new skills guide existing canonical commands with discriminating triggers and truthful completion criteria.
- OpenSpec examples load conditionally; validated planning and bounded authorization survive workflow handoffs.
- The local preparer publishes private, validated, no-clobber intent/mapping files without opening credentials or contacting infrastructure.
- Realistic held-out evaluation scenarios cover scope, failed preflight, cleanup interruption and incomplete live evidence.
- Relevant tests, required local gate and exact-head hosted checks pass; independent review names remaining limits.
