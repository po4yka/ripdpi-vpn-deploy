## Implementation and verification

- Baseline from nine hosted `ci.yml` runs on 2026-10-23/24: full runs took 55-84 minutes (median about 61) and about 490 runner-minutes over 93 jobs. The critical path was the serial 51-minute pytest step of `native runtime integration`; the portable suite measured 50.7 CPU-minutes on one core per group.
- Native runtime runs as three disjoint matrix parts with a measured `tests/native/native-runtime-durations.json` profile; transport runtime acceptance uses three `least_duration` groups on the existing recovery profile. Local collection estimates: native runtime groups 634.81 s each, transport groups 1281-1348 s. The collection test proves both complete disjoint unions.
- Portable pytest runs under pytest-xdist 3.8.0 (`--dist loadfile`) locally and in each CI group. A real two-worker regression proves the shard report and verifier still reject incomplete or overlapping coverage. The duration profile is refreshed from main run 40002002857 and covers all 10,195 portable tests; each group now estimates 672.49 s before worker parallelism.
- The selector skips native lanes for portable-only `tests/unit` module edits and lets a main push reuse a full successful PR run of the same tree. Checked live (read-only): main 2e6a8ff2 maps to full PR run 39993499831, while ec655f03 keeps full CI because its PR run was a selective plan.
- `make check` drops the duplicate docs guards, shares one Ansible syntax check and one Terraform init per provider, and runs under `make -j`. `make -j2 terraform-init tf-test` passed all four providers (73/55/59/47 Terraform tests) and its 18 pytest cases.
- Intel macOS vpnd runners are removed. The restore-completeness module shares one initialized restic repository: 285 s to 139 s back to back, 52 passed.
- `make -j4 -k check` completed in 677 s on a machine with load averages of 50-500 from unrelated work. Failures were environment drift: local setuptools 84.0.0 instead of 84.2.1 (`vpnd-package-check` and one vpnd install test), local sing-box 1.13.16 instead of 1.14.3 (`liveness-profile-check`), and the known real-SOPS/mise HOME-trust tests (12 failed and 70 errors that also fail serially). Two parallel-only timeouts pass serially; the collection hang guards were widened. One real order defect (umask-dependent receipt mode) was fixed.
- An independent static review found no coverage loss; its findings on reuse ancestry, pagination, HTTP errors, closure sources and documentation were addressed.
- Hosted CI runtime of the new native parts and groups, the PR wall time and a reused main push remain to be observed.
