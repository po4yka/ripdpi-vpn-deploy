# SCR-1787420815046709: Fix high-priority audit findings in operator scripts

## Objective

Six high-priority audit findings in operator-side tooling are fixed with
regression coverage: burn-check no longer classifies still-pending
check-host.net nodes as burned; wait-cloud-init fails loudly when SSH never
comes up or the bootstrap marker is missing; destroy.sh refuses to run over a
stale `_destroy_override.tf`; audit-log serializes concurrent appends;
decrypt-secrets defaults to a volatile, backup-excluded runtime directory; and
operator/sentinel logs move out of world-writable `/tmp` into owner-only state
directories.
