## Purpose

Provide observable, testable guarantees for deliver isolated native acceptance for every baseline transport across accepted inputs, successful operation, failure and retained authority.

## ADDED Requirements

### Requirement: REQ-PROTO-NATIVE-COMPLETION — Actual four-protocol completion

The implementation MUST complete authenticated REALITY, primary and alternate XHTTP, Hysteria with and without Salamander, and every bound AWG instance using exact pinned real executables; baseline alternate-server proof uses the existing listener and endpoint-derived native configuration without requiring the later alternate-delivery feature or crediting it as delivered.

#### Scenario: All enabled shapes pass

- **WHEN** isolated native services use the shared effective contract
- **THEN** real clients complete bidirectional HTTPS/TCP/UDP/DNS as appropriate and AWG records a fresh handshake

#### Scenario: Credentials or TLS are wrong

- **WHEN** one client uses wrong authentication or wrong certificate identity
- **THEN** that transport fails while a control client remains healthy

### Requirement: REQ-PROTO-NATIVE-LIFECYCLE — Upgrade and retirement proof

The implementation MUST observe actual process executable/unit adoption and removal of retired traffic paths without touching foreign resources.

#### Scenario: Warm pin and unit upgrade

- **WHEN** only AWG source pin or rendered unit changes
- **THEN** every current daemon adopts the candidate and sandbox, then unchanged convergence causes no restart

#### Scenario: Profile or instance retires

- **WHEN** two instances become one or a transport is disabled
- **THEN** owned interfaces/listeners/credential traffic stop and foreign tunnels and queues survive

### Requirement: REQ-PROTO-NATIVE-COMPENSATION — Runtime and nginx failure recovery

The implementation MUST prove complete old authority remains usable after candidate failures or interruptions and log rotation restores active Xray.

#### Scenario: Candidate adoption fails

- **WHEN** runtime config, TLS, assets, bind or readiness fails or activation is killed
- **THEN** exact preceding authority resumes authenticated traffic or explicit private recovery debt remains and success is refused

#### Scenario: Rotation and fallback privacy

- **WHEN** nonempty Xray logs rotate and alternate XHTTP carries traffic
- **THEN** Xray returns active within its contract and nginx logs contain no transport markers

### Requirement: REQ-PROTO-NATIVE-HOPPING — Real firewall-owned hopping

The implementation MUST prove Hysteria range ingress works for both IP families without NET_ADMIN in the daemon and without redirecting unrelated outbound UDP.

#### Scenario: Range hopping is active

- **WHEN** clients traverse distinct declared range ports over IPv4 and IPv6
- **THEN** authenticated traffic continues and unrelated UDP keeps its destination

#### Scenario: Range is removed

- **WHEN** profile disables hopping and converges twice
- **THEN** only owned redirect rules disappear and the ordinary listener remains usable

### Requirement: REQ-PROTO-NATIVE-HONESTY — Scoped exact-source results

The implementation MUST fail a selected suite on missing binaries, missing capabilities, skipped cases or cleanup uncertainty and distinguish native results from provider, physical device and live receipt.

#### Scenario: Prerequisite or cleanup is missing

- **WHEN** selected Linux capabilities, pinned artifact or owned resource cleanup fails
- **THEN** nonzero result lists the exact unsatisfied category and never reports protocol success

#### Scenario: Results are published

- **WHEN** a complete native run finishes
- **THEN** private redacted evidence names exact source, engine digests, requirement cases and cleanup outcomes without promoting any node
